📘 PLAN.MD — План разработки RuStore MVP
🎯 Цель проекта

Реализовать MVP мобильного магазина приложений RuStore на Android с базовым функционалом: список приложений, карточка приложения, отображение скриншотов, описание, установка/удаление и навигация.

В рамках MVP используются локальные мок-данные, Jetpack Compose, Hilt, Navigation, Coil.

🗂 Эпики проекта
Epic 1 — Базовая архитектура и настройка проекта

Срок: 3 дня

Задачи

 Инициализация Android Studio проекта + GitHub репозитория (0.5 дня)

 Подключение Compose, Material 3, Navigation, Hilt, Coil (0.5 дня)

 Настройка DI (Hilt): AppModule, ViewModel-injection (0.5 дня)

 Создание структуры пакетов presentation / domain / data (0.5 дня)

 Добавление навигации NavGraph (1 день)

Epic 2 — Каталог приложений (Apps List)

Срок: 4 дня

Задачи

 Создать модель AppDetails + enum Category (0.5 дня)

 Написать AppCatalog с мок-данными (1 день)

 UI списка: LazyColumn, AppListItem (1 день)

 Навигация: переход по клику на приложение (0.5 дня)

 Обработка категорий, отображение developer, иконки, имени, размера (1 день)

Epic 3 — Карточка приложения (App Details)

Срок: 5 дней

Задачи

 Структура UI: Toolbar, Header, характеристики (1 день)

 Экран AppDetailsContent (каркас + состояние Content/Loading/Error) (1 день)

 Отображение скриншотов (горизонтальный или вертикальный список) (1 день)

 Блок "Описание приложения" + "Читать подробнее" (0.5 дня)

 Блок "Разработчик" с кликабельным переходом (0.5 дня)

 Общий UI-полиш и размеры/отступы (1 день)

Epic 4 — Состояния и ViewModel логика

Срок: 3 дня

Задачи

 Создать AppDetailsState (Loading / Error / Content) (0.5 дня)

 Загрузка данных из AppCatalog по ID (0.5 дня)

 К collapsе/expand описания (0.5 дня)

 События: Snackbar → Installed, Uninstalled, UnderDevelopment (1 день)

 Поддержка Live обновления UI через StateFlow (0.5 дня)

Epic 5 — Установка / Удаление приложения

Срок: 3 дня

Задачи

 Кнопка InstallButton: состояния «Установить» / «Удалить» (1 день)

 ViewModel: методы installApp() / uninstallApp() (1 день)

 Snackbar-уведомления (1 день)

Epic 6 — Финализация UI и тестирование

Срок: 2 дня

Задачи

 Проверка всех экранов, исправление багов (1 день)

 UI-тестирование макетов на разных устройствах (0.5 дня)

 Подготовка README + скриншоты + ссылка на GitHub (0.5 дня)
