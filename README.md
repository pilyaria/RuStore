# 📱 RuStore — Android-приложение на Jetpack Compose

Добро пожаловать в **RuStore** — учебный проект Android-приложения, созданный для изучения
Jetpack Compose, архитектуры MVVM, навигации и работы с данными.  
Проект аккуратно вдохновлён интерфейсами RuStore и Google Play.

---

## 🚀 Возможности

- 🔍 Просмотр списка приложений  
- 📄 Экран деталей приложения  
- 🖼 Загрузка и отображение иконок и скриншотов  
- 🔙 Навигация между экранами (Jetpack Navigation)  
- 🍭 UI полностью на **Jetpack Compose**  
- 📦 DI через **Hilt**  
- 🎨 Material 3  
- 🔧 Готов к расширению: можно добавить реальные API / БД
